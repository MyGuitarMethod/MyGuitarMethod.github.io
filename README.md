# MinnyMedia publisher verification

Public verification-only hosting for MinnyMedia apps, published with GitHub Pages from `MyGuitarMethod/MyGuitarMethod.github.io`.

The AdMob authorized seller record is available at:

https://myguitarmethod.github.io/app-ads.txt

The publisher record was supplied in the developer's AdMob setup screen:

```text
google.com, pub-4880864056947626, DIRECT, f08c47fec0942fa0
```

The Google Play developer website for Spirit Dragon remains:

https://myguitarmethod.github.io/Spirit-Dragon-landing/

AdMob uses the hostname of that website and checks `/app-ads.txt` at its root, not inside the project folder. The existing game landing pages and privacy policies remain in their own repositories.

This repository contains only a public seller record, a minimal index, this documentation and `.nojekyll`. Do not add game source, Android builds, keys, passwords or credentials. Do not configure a custom domain: this host also serves existing project Pages websites.
